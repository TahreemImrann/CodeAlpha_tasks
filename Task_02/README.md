# CodeAlpha Task 2 — Language Learning App

## Overview

A Flutter-based language learning application developed as part of my CodeAlpha App Development Internship. The app combines vocabulary learning, interactive flashcards, quizzes, categories, and progress tracking in one learning experience.

## Features

- Multiple language options
- Vocabulary learning
- Common phrases
- Grammar-focused learning content
- Translations
- Pronunciation information
- Interactive flashcards
- Tap-to-reveal translations
- Example sentences
- Mark lessons/cards as mastered
- Quiz and practice mode
- Quiz score tracking
- Quiz progress indicator
- Category filtering
- Learning progress tracking
- Daily streak tracking
- Local progress persistence using SharedPreferences
- Material 3 interface
- Haptic feedback and polished learning interactions

## Supported Languages

The current learning content includes:

- French
- Spanish
- German
- Japanese

## Technologies Used

- Flutter
- Dart
- Material 3
- SharedPreferences for local progress persistence
