# CodeAlpha Task 1 — Flutter Flashcards

## Overview

A Flutter-based flashcard application developed as part of my CodeAlpha App Development Internship. The app is designed for learning and revising Flutter and Dart concepts through interactive flashcards.

## Features

- Interactive question and answer flashcards
- Tap to reveal or hide answers
- Next and Previous card navigation
- Swipe gestures for learning actions
- Mark cards as **Mastered** or **Need Practice**
- Topic/category filtering
- Add new flashcards
- Edit existing flashcards
- Delete flashcards with confirmation
- Card progress indicator
- Form validation
- Haptic feedback for key interactions
- Material 3 based user interface
- Empty-state handling

## Topics Covered

The sample flashcards cover areas including:

- Rendering Architecture
- State Management
- Asynchronous Dart
- Layout & Rendering
- Performance & Memory
- Custom Painting
- Keys & State Persistence
- Engine & Platform Interoperability
- Build Lifecycle
- Advanced Navigation

## Technologies Used

- Flutter
- Dart
- Material 3

## How to Run

1. Make sure Flutter is installed.
2. Clone the repository.
3. Open the Task 1 project folder.
4. Run:

```bash
flutter pub get
flutter run
```
